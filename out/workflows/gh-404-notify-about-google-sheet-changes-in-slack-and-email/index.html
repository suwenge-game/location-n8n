Notify about Google Sheet changes in Slack and email

来自 N8N 社区模板库的真实工作流：5 个节点，核心链路 IF → Slack → IF → Send Email。

这个工作流做什么

该流程由 Typeform Trigger 发起，共包含 5 个节点。数据进入后依照 4 条连接关系流转，主要通过IF（条件分支）、Google Sheets（读写 Google 表格）、Send Email（发送邮件）、Slack（发送 Slack 消息）完成自动化任务。你可以结合下方节点表和数据流向，快速判断需要配置哪些服务与凭证。

节点结构

名称类型作用说明

IFif条件分支
Google SheetsgoogleSheets读写 Google 表格
Send EmailemailSend发送邮件
Slackslack发送 Slack 消息

数据流向

  1. 01IF → Slack
  2. 02IF → Send Email
  3. 03Google Sheets → IF
  4. 04Typeform Trigger → Google Sheets
